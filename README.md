# bong
It's a small program that notifies you with a sound when a long running command finishes.

## Usage
bong nmap -sV 192.168.1.1

## Installation
git clone https://github.com/yourusername/bong.git\
cd bong\
chmod +x bong.sh\
sudo cp bong.sh /usr/local/bin/bong\

## Requirements
- Any linux Distro 
- MPV
